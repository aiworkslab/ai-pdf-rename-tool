# AI Works Lab Codex Instructions

## Project Goal

This project is part of AI Works Lab.

The goal is to build small practical tools step by step and publish the progress on GitHub, X, and note.

## Coding Rules

* Keep the code beginner-friendly.
* Do not add unrequested features.
* Do not change existing behavior unless requested.
* Prefer simple code over clever code.
* Use Japanese comments where helpful.
* Do not remove existing comments without a reason.

## Safety Rules

If adding safety checks or extra conditions, explain:

* What was added
* Why it was added
* Possible side effects

Do not silently add extra logic.

## Output Rules

After making changes, always summarize:

1. What changed
2. Why it changed
3. How to test it
4. Suggested Git commit message in English / Japanese
5. README update suggestion
6. One-line code explanation for beginners

## User Preference

The user is learning Python.

Explain changes in simple Japanese.

The user wants commit messages in this format:

English / Japanese

Example:

Add rename result file list display / リネーム結果ファイル一覧表示追加
